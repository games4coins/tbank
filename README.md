## TBank Radar
Откройте index.html локально для демо. Добавьте секрет TBANK_TOKEN в Settings → Secrets and variables → Actions. Токен только для чтения. Actions → Dividend data → Run workflow. Сборщик сохраняет рыночные события в data.json, не портфель. Для Pages выберите Settings → Pages → Source → GitHub Actions, затем запустите Publish calendar вручную. Для автоматической публикации после сбора установите repository variable PUBLISH_PAGES=true. GitHub Free требует публичный репозиторий. Реальные данные не проверены без токена. Демо содержит условные суммы.
