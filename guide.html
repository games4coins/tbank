◉ TBANK RADAR — руководство

Главная · Рынок · Облигации

1. Начало работы

Откройте главную страницу, введите пароль PORTFOLIO_PASSWORD (не токен брокера), нажмите «Открыть портфель». Выберите счёт. Количество акций заполнится автоматически; единый календарь покажет известные будущие дивиденды и купоны. Без разблокировки ручные количества — только модель. Не вводите пароль на сторонних сайтах.

Если купоны отсутствуют, запустите Dividend data в режиме portfolio, затем Publish calendar при отключённой автоматической публикации. Снимок не синхронизируется в реальном времени.

2. Дивиденды и купоны

Выберите год, предстоящие выплаты или отсечки. Нажмите название акции для истории выплат. Нажмите месяц для списка событий. В разделе облигаций отдельно разблокируйте портфель, выберите «Мои / выбранные». Неизвестные выплаты не равны нулевому доходу. История, рассчитанная по текущим количествам акций, не является фактическими выплатами. YTM — оценка только для простых выпусков; проверяйте оферту, кредитное качество и ликвидность у брокера.

3. Поиск торговых идей

На странице рынка выберите дневной или пятиминутный интервал, голубые фишки и фильтр сигнала. RSI ниже 30 означает перепроданность по индикатору, но не гарантирует разворот. EMA9 выше EMA21 — описание краткосрочного тренда. MACD — разница EMA12 и EMA26; ATR — диапазон волатильности; относительный объём сравнивается с предыдущими 20 свечами; VWAP — приближение по свечам. Перед любой сделкой проверяйте цену, стакан, новости и спред у брокера. Снимки GitHub запаздывают и не годятся для исполнения скальпинговых сигналов.

4. Проверка стратегии

Выберите акцию и стратегию, задайте комиссию и проскальзывание, запустите бэктест. Проверьте количество сделок, доходность, просадку и profit factor. Малую выборку нельзя считать доказательством эффективности. Тестируйте на разных периодах и инструментах, учитывайте внутрисделочные просадки, которые текущий тест не измеряет. Начните с виртуального журнала; не переносите автоматически удачный исторический результат на реальный капитал.

5. План сделки

В калькуляторе long укажите выделенный торговый капитал, допустимый риск, вход, стоп, цель, лот и расходы. Размер позиции ограничен капиталом и расчётным риском. Стоп может исполниться хуже указанной цены. Математическое ожидание зависит от заданной доли побед, а не предсказывает её. Виртуальные сделки закрываются вручную; брокеру заявки не отправляются.

6. Цель дохода

100 000 ₽ в месяц при капитале 4 млн ₽ — 30% годовых до расходов и налогов. Используйте календарь для оценки неравномерности денежных потоков и резервов, а не как обещание доходности. Отделяйте купоны, дивиденды, изменение цены и фактическую прибыль по закрытым сделкам.

7. Обновление данных

GitHub Actions: Dividend data — дивиденды и портфель; Market radar — рыночные свечи; Bond calendar — купоны и облигации; Publish calendar — публикация сайта. При PUBLISH_PAGES=true публикация запускается после успешного сбора. Запускайте новый workflow из main, не повторяйте старый коммит. Секреты не передавайте в чат.
